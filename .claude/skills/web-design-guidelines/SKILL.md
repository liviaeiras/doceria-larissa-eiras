# Web Interface Guidelines (cópia fixada)

Adaptado de `vercel-labs/agent-skills` (MIT). A versão original baixa as regras da internet a cada uso; aqui elas ficam fixadas em `guidelines.md` (vercel-labs/web-interface-guidelines, commit `434b7f9`, 2026-10-05) para não depender de rede nem de conteúdo remoto não revisado.

## Como usar

1. Leia `guidelines.md` desta pasta (uma vez por revisão).
2. Leia só os arquivos indicados pelo usuário (ou pergunte quais).
3. Aplique as regras e reporte no formato `arquivo:linha — problema — correção`, agrupado por gravidade.
4. Não corrija nada sem o usuário pedir; esta skill é de revisão.

Para atualizar as regras: baixe de novo `command.md` do repositório oficial, revise o conteúdo e substitua `guidelines.md`, anotando o novo commit acima.
